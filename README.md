# Veri Yapıları ve Algoritmalar

Veri Yapıları ve Algoritmalar dersinde C ile yazdığım temel yapılar ve algoritmalar.

![C](https://img.shields.io/badge/C-A8B9CC?logo=c&logoColor=black)

| Klasör | Konu |
|---|---|
| [`bagli-liste/`](bagli-liste/main.c) | Tek yönlü bağlı liste: başa ekleme, listeyi yazdırma |
| [`bagli-liste-ve-arama/`](bagli-liste-ve-arama/main.c) | Bağlı listede başa, sona ve araya ekleme, silme; doğrusal ve ikili arama |
| [`dairesel-kuyruk/`](dairesel-kuyruk/main.c) | Sabit kapasiteli dizi ile dairesel kuyruk: ekleme, çıkarma, dolu/boş kontrolü |
| [`yigin/`](yigin/main.c) | Yığın (stack): ekleme, çıkarma, dolu yığın kontrolü |
| [`insertion-sort/`](insertion-sort/main.c) | Eklemeli sıralama |

## Derleme

```bash
gcc bagli-liste-ve-arama/main.c -o arama
./arama
```
